# Unity 2D Game Development Course Projects

This repository contains my Unity 2D game development projects completed as part of a comprehensive Udemy course on 2D game development in Unity.

## 🎮 Game Projects

### 1. **Glitch Garden** 
*Tower Defense Game*
- **Genre:** Tower Defense
- **Features:** Defender placement, enemy waves, resource management
- **Scripts:** Attacker AI, Defender mechanics, Spawning system
- **Key Learning:** Object pooling, game balance, UI design

### 2. **TileVania**
*2D Platformer*
- **Genre:** Platformer
- **Features:** Player movement, jumping, enemy AI, collectibles, level progression
- **Scripts:** Player controller, Enemy movement, Pickup systems, Game session management
- **Key Learning:** Physics-based movement, collision detection, level design

### 3. **Laser Defender (Chicken Invaders)**
*Space Shooter*
- **Genre:** Shoot 'em up
- **Features:** Player shooting, enemy waves, path following, health system
- **Scripts:** Player control, Enemy pathing, Wave configuration, Damage system
- **Key Learning:** Object movement patterns, audio management, game progression

### 4. **Maple Block Breaker**
*Breakout/Arkanoid Style*
- **Genre:** Arcade
- **Features:** Ball physics, paddle control, destructible blocks, level progression
- **Scripts:** Ball movement, Paddle control, Block destruction, Level management
- **Key Learning:** Physics materials, collision events, level design

### 5. **Number Wizard UI**
*Number Guessing Game*
- **Genre:** Puzzle
- **Features:** Binary search gameplay, UI interactions, scene management
- **Scripts:** Game logic, UI controllers, Scene loading
- **Key Learning:** UI design, state management, user input handling

### 6. **Text101**
*Text Adventure*
- **Genre:** Interactive Fiction
- **Features:** Story branching, text-based gameplay, state management
- **Scripts:** Adventure game controller, State system
- **Key Learning:** Narrative design, state machines, text UI

### 7. **Underground Madness**
*2D Platformer*
- **Genre:** Platformer
- **Features:** Character movement, level navigation
- **Key Learning:** Basic Unity 2D setup and fundamentals

## 🛠️ Technologies Used

- **Engine:** Unity 2D
- **Language:** C#
- **Version Control:** Git
- **IDE:** Visual Studio / Visual Studio Code

## 📚 Skills Developed

- **Core Unity Concepts:** GameObjects, Components, Prefabs, Scenes
- **C# Programming:** Object-oriented programming, event handling, coroutines
- **2D Game Development:** Sprite handling, animations, physics
- **Game Design Patterns:** Singleton, Object Pooling, State Management
- **UI/UX:** Canvas design, responsive UI, user interaction
- **Audio:** Sound effects, background music, audio mixing
- **Level Design:** Tilemaps, collision layers, scene transitions
